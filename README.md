# 📊 Dashboard Gerencial de Apostas Esportivas (Bets)

Painel analítico e interativo desenvolvido em **Python** utilizando **Streamlit** e **Plotly**, criado como projeto prático para o curso de Gestão de Dados da **UFPI (Universidade Federal do Piauí)**.

## Sobre o Projeto
O objetivo deste painel é simular o monitoramento gerencial de risco, volume apostado e desempenho financeiro em plataformas de apostas esportivas, permitindo a análise rápida de métricas por modalidade, região e status das apostas.

## Princípios de Visualização de Dados aplicados
- **Mantra de Shneiderman:** Visão geral (*overview*) no topo via KPIs e gráficos agregados, filtros interativos na barra lateral (*zoom and filter*), e tabela analítica detalhada na parte inferior (*details-on-demand*).
- **Brushing & Linking:** Interação sincronizada entre os filtros da barra lateral e os gráficos.
- **Data-Ink Ratio de Tufte:** Layout limpo e direto, focado na maximização da proporção de tinta dedicada aos dados.
- **Acessibilidade:** Paleta de cores planejada para contraste e legibilidade (*colorblind-friendly*).

## Tecnologias Utilizadas
- **Python** (Linguagem principal)
- **Streamlit** (Framework para construção do dashboard web)
- **Pandas & NumPy** (Manipulação e simulação de dados)
- **Plotly** (Gráficos interativos)
